
# ♻️ WasteTrade

### Community Waste-to-Value Platform

WasteTrade is a Django-based web application that connects customers with local scrap dealers to make recyclable waste collection easier, more transparent, and convenient.

## Features

- Customer and Dealer Registration & Login
- Role-Based Access Control
- Admin Dealer Verification
- Customer Dashboard
- Add Multiple Waste Items to Basket
- Edit and Remove Waste Items
- Condition-Based Price Estimation
- Admin-Managed Waste Rates
- Waste Pickup Requests
- Dealer Waste Acceptance
- Pickup Scheduling

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Django
- **Database:** SQLite
- **Version Control:** Git & GitHub

## Project Status

🚧 **Under Development**

Customer and dealer modules are being developed and tested.

Upcoming features include Collector Management, Actual Weight Verification, Final Amount Confirmation, and Offline Payment Tracking.

## Run Locally

1. Clone the repository.
2. Create a Python virtual environment.
3. Install dependencies from `requirements.txt`.
4. Configure the Django environment variables.
5. Run database migrations.
6. Start the development server.

```powershell
cd backend
python manage.py migrate
python manage.py runserver
```
